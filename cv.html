Tslator: A Compiler for TSLANG

2025

Built compiler for educational C-like language (TSLANG) using Python and PLY. Implemented lexical analysis, parsing, semantic analyzer with scoped symbol tables, type checking, AST construction, and intermediate representation (IR) code generation. PyThreadServe: Multi-Process HTTP/1.0 Server with Concurrency Control

2025

Implemented lightweight HTTP/1.0 server in Python with multi-process architecture and thread pooling. Features include GET/POST support, round-robin load balancing, thread-safe file operations, directory traversal protection, and comprehensive logging with configurable concurrency limits.
