Deep Learning for Automatic Sleep-Stage Classification from EEG Signals

2026 | Deep Learning & Biomedical Signal Processing

Built a deep learning pipeline that automatically classifies sleep stages (Wake, NREM, REM) from EEG and EMG recordings, reaching 86.7% accuracy on unseen animals using the OpenNeuro ds006366 dataset (92 subjects, ~128K labeled 4-second epochs). Four architectures were designed and compared — an MLP baseline on handcrafted features, a 1D CNN over raw signals, a CNN combined with a bidirectional LSTM, and a CNN-backbone Transformer. The work emphasizes rigorous methodology: subject-level splits to prevent data leakage, class-weighted loss to handle the severe 7% REM imbalance, global normalization, temporal context modeling, and GPU-accelerated augmentation, with thorough evaluation through confusion matrices, ROC curves, and per-subject metrics.

Deep Learning PyTorch EEG Analysis CNN-LSTM Transformers Signal Processing Healthcare AI

Real-Time Driver Drowsiness Detection

2026 | Computer Vision & Deep Learning

Developed a real-time system that detects driver drowsiness from video by recognizing sustained eye closure while filtering out normal blinks. The pipeline combines MediaPipe's Face Landmarker to locate and crop eye regions with a CNN eye-state classifier trained on the MRL Eye Dataset, achieving 97.4% accuracy and 97.5% recall on closed eyes to prioritize safety. A temporal filtering mechanism raises alerts only when the closed-eye probability stays above threshold for a configurable duration, and the system works with recorded video, webcam feeds, or live streams.

Network Intrusion Detection with Machine Learning

2026 | Machine Learning & Cybersecurity

Designed an end-to-end machine learning pipeline that classifies network connections as normal or malicious using the KDD Cup 1999 dataset, refining roughly 494K raw records into 145K clean samples across 41 features. The 12-stage workflow covers exploratory analysis, missing-value imputation, quantile-based outlier clipping, one-hot encoding, standard scaling, Truncated SVD dimensionality reduction, and MiniBatch K-Means clustering, followed by a comparison of Dummy, Logistic Regression, and Random Forest classifiers. The Random Forest model reached 99.91% accuracy with a 1.0 ROC-AUC for attack detection, supported by detailed metrics and visualizations.
